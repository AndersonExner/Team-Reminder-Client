# Checklist manual

- [ ] Instalar sem startup selecionado: registro ausente e app abre normalmente.
- [ ] Instalar com startup: registro aponta para exe instalado com --tray; logout/login inicia oculto.
- [ ] Configurações habilita/desabilita startup; gerenciador de tarefas pode desativar a entrada.
- [ ] Fechar janela: processo permanece, alarme toca; abrir pelo ícone restaura.
- [ ] Tooltip e menu mostram próximos alarmes e atualizam após salvar/disparar/excluir.
- [ ] Adicionar foca título; edição em andamento é preservada com orientação.
- [ ] Sair remove ícone/processo; reabrir não repete alarme já entregue.
- [ ] Duplo clique, clique direito, teclado e Explorer reiniciado recuperam acesso à bandeja.
- [ ] Segunda instância restaura janela existente; não abre segundo banco.
- [ ] Desinstalar remove startup/arquivos; banco e preferência de tema permanecem.
- [ ] Tema claro/escuro, DPI 100/150/200% e ícone em ícones ocultos.
