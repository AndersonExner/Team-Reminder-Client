# Checklist manual
- Criar Bater ponto com link HTTPS, reiniciar e editar.
- Disparo não abre navegador; botão no toast/lista/aviso local abre URL com query/fragmento.
- Corpo do toast somente restaura app.
- Sem texto usa Abrir link; remover ambos remove botão.
- Cancelar preserva; editar após disparo não altera aviso antigo.
- Dispensar limpa avisos/botões; testar notificações bloqueadas e temas.
- Falha de navegador não provoca novo disparo.
