# Revisão manual

- [ ] Tela principal tem Novo alarme e lista, sem formulário fixo.
- [ ] Novo e bandeja Adicionar abrem modal; título recebe foco; data/hora correspondem ao momento de abertura.
- [ ] Recorrência semanal mostra dias; erros de título/data/recorrência mantêm modal e campos.
- [ ] Salvar fecha após sucesso, atualiza lista; falha no banco não fecha.
- [ ] Editar preenche horário salvo; Cancelar/Esc não modifica banco, reabrir Novo traz campos limpos.
- [ ] Clique repetido/bandeja com diálogo aberto não abre segunda modal nem limpa dados.
- [ ] Tema claro sem preferência/inválida; escuro/Windows salvos permanecem; modal acompanha tema.
- [ ] Alarme toca com modal aberto; fechar/restaurar janela preserva modal; rolagem/DPI/teclado acessíveis.
