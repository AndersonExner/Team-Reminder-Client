# Verificação manual

- [ ] Alternar Claro/Escuro/Windows e conferir texto, seleção, foco e controles de data/hora.
- [ ] Excluir em ambos os temas: diálogo acompanha tema; cancelar mantém dados.
- [ ] Reiniciar em cada tema; arquivo ausente/inválido usa Windows.
- [ ] Alterar tema do Windows com Padrão do Windows selecionado.
- [ ] Redimensionar de 1160 para 800 e 600 px: formulário empilha, rolagem permite salvar.
- [ ] Navegar por Tab/Shift+Tab; rótulos de controles e botão Atualizar acessíveis.
- [ ] Trocar abas e redimensionar durante edição preserva campos e dias.
- [ ] Criar/editar/excluir/recorrência e disparo com Configurações aberta.
- [ ] Muitos alarmes: rolagem da lista e acesso ao formulário.
